# 分类标签

技能用五个规范角色描述分类状态。本文件把这些角色映射到本仓库追踪器中实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需评估该问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给无人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时（例如「打上可交给 agent 的标签」），使用本表右列的字符串。

需要更换词表时，直接改右列。
