# 08: 回放指标与概览栏

**What to build:** 运维者能在管理界面判断回放是否真的在工作，以及失败原因属于哪一类。概览页增加一栏：存储模式、命中率、已存字节、无效标记次数、外来条目次数、被抑制次数、弱作用域条目数。不做独立页面，不展示会话明细。

**Blocked by:** 02、04、05

**Status:** ready-for-agent

- [ ] 计数包含：还原成功、`replay_invalid`、`replay_foreign`、`replay_suppressed`、`replay_rejected`、生成标记、已存字节、弱作用域条目数
- [ ] 命中率 = 还原成功次数 ÷ 带标记的请求数
- [ ] 概览页显示存储模式、命中率、已存字节与三类失败计数
- [ ] 命中率归零时能从界面看出「客户端可能剥离了注释」
- [ ] 不新增独立页面，不展示会话明细
