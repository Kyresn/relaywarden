# 05: 被拒分类与拒绝记忆

**What to build:** 上游拒绝回放的推理载荷时，插件能识别并分类记录，不再每轮反复撞同一面墙。同一作用域被拒后，进程内记住一段时间，后续请求直接跳过展开，只删标记并计数。

记忆只存在进程内，容量有上限，重启清空。识别不到稳定拒绝特征时，退化为「带还原条目的请求失败率 vs 不带条目的基线」对比，只记录，不启用记忆。

**Blocked by:** 01（拒绝特征结论）、02

**Status:** ready-for-agent

- [ ] 上游拒绝回放时 `replay_rejected` 计数加一
- [ ] 被拒后同一作用域的下一次请求不再展开，`replay_suppressed` 加一
- [ ] 拒绝记忆容量有上限，按最旧淘汰
- [ ] 记忆 TTL 与条目 TTL 一致，重启清空
- [ ] 识别不到稳定特征时，只记录失败率对比，不抑制后续请求
- [ ] 文档写明记忆不持久化
